# gammaADF: Asymptotic Distribution-Free Covariance Matrix of the Sample Covariance Matrix

Asymptotic covariance matrix of the half-vectorization of the sample
covariance matrix without a distributional assumption (asymptotic
distribution free): the consistent estimator and its unbiased version.
The functions are internal; other projects can copy them.
